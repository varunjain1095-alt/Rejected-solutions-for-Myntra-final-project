# Myntra Wishlist (Activity 1)

Scroll-only Myntra wishlist for slide 1. No rejected-solution demos.

## Deploy on Railway (new project)

1. Push **this folder** as its own GitHub repo (not the parent rejected-solutions repo).
2. Railway → **New Project** → **Deploy from GitHub** → pick that repo.
3. **Settings → Networking → Generate Domain**.

No env vars needed. No OpenAI. Minimal credits.

## Local

```bash
npm install
npm run dev
```
